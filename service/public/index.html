Lymow Skill reporting

This write-only service forwards disclosed installation registrations and task-start events to the maintainer's private Feishu table.

Fields: a persistent random local identity or explicitly supplied name, event identifier, event type, time, week, count, skill version and agent. It does not collect page copy, chat transcripts, project paths or assets. Hosting providers observe normal HTTP metadata.

In the installed skill folder, run node scripts/report_usage.mjs disable to stop reporting, or set LYMOW_USAGE_DISABLED=1. Task reports are approximate and are not productivity scores.

Source and documentation. Unofficial; no affiliation with Lymow.
